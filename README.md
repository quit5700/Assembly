# 个人程序集

用于集中管理本地小程序的 Windows（视窗系统）桌面工具。当前版本：v2.0.5。

## 下载与使用

在本仓库的版本发布页下载“小程序集合.exe”，放进准备管理程序的文件夹后运行。
支持添加程序、添加文件夹、扫描整理、双击运行、拖动排序，以及右键打开目录、编辑简介、更换图标和删除。
删除前会要求确认；确认后将整个程序文件夹移入用户数据目录的“已删除”文件夹，并移除界面条目，不是永久删除。当前没有一键恢复。
数据库、图标和已删除程序保存在当前用户的应用数据目录 PersonalSuite（个人程序集）。不要把个人数据库或备份提交到本仓库。

## v2.0.5 修复

避免旧窗口的扫描、排序或图标修改覆盖后来保存的简介。保存时比较读取快照与磁盘最新数据，合并不同字段的修改；同字段冲突时停止保存并提示。读取损坏数据时停止启动，备份失败时停止写入。
保留主动清空简介功能。旧版本没有这项保护，建议使用最新版本。

## 从源码运行与构建

使用 Python（编程语言）3.13；Tkinter（图形界面库）通常由 Windows 版 Python 安装程序提供。Pillow（图像处理库）用于图标，PyInstaller（程序打包工具）用于生成可执行文件。

```powershell
python -m pip install -r requirements.txt
python '.\小程序集合.py'
```

构建时运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File '.\构建.ps1'
```

输出位于“打包输出”文件夹。部署时将可执行文件放到实际管理程序的文件夹，避免把源码和构建目录作为被管理的程序。

```powershell
$env:PYTHONUTF8 = '1'
$env:PYTHONIOENCODING = 'utf-8'
python -m unittest discover -s tests -v
```
